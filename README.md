# Variable Stroke for Glyphs 3

中心線から可変幅のアウトラインを作る Glyphs 3 プラグインです。

## インストール

`VariableStrokeTool.glyphsTool` と `VariableStrokeExport.glyphsFilter` の両方を Glyphs 3 の Dock アイコンへドラッグし、Glyphs 3 を再起動してください。Glyphs の Python モジュールも必要です（ウインドウ → プラグインマネージャ → Modules）。

## 使い方

1. 編集画面で中心線となる開いたパス、または閉じたパスを描き、ノードを選択します。レイヤーにパスが1本だけなら選択せずに操作できます。
2. ツールバーで **可変ストローク** を選び、画面下部のパネルで **ストロークを有効にする** をチェックします。初期幅は40ユニットです。チェックを外すと元のパス表示に戻ります。
3. パネルの **線幅** を入力するか、青い幅ハンドルをドラッグします。ノード選択中は選択ノードの幅を変更し、ノード未選択時は対象パス全体の幅を変更します。中心線とベジェハンドルは Glyphs の通常の操作で編集できます。
4. パネルの **始点の線端** と **終点の線端** で、それぞれ線端を選びます。閉じたパスでは線端設定は使いません。
5. パネルの **アウトライン化**、または **フィルタ → 可変ストローク：アウトライン化** で手動変換できます。元の編集データを残すには、変換前にレイヤーを複製してください。

書き出し用の `Filter` カスタムパラメータは、ストロークを有効にしたとき各インスタンスへ自動追加されます。書き出し時は生成されたアウトラインが使われ、編集元の中心線は `.glyphs` ファイルに残ります。新しいインスタンスを後から追加した場合は、ツールを一度選択してパラメータが追加されたことを確認してください。

## データと制限

- パスの設定は `attributes`、ノードごとの幅は `userData` に保存されます。幅は中心線から両側へ対称です。
- 水平・垂直カットは端点を通り、ページ座標に固定されます。パスの進行方向がカット線とほぼ平行な場合、端部に鋭い折り返しが生じることがあります。
- アウトラインはサンプリングした直線ノードで生成します。大きく拡大して使うフォントでは、アウトラインの仕上げ確認を推奨します。
- 直線と三次ベジェに対応します。二次ベジェ、孤立したオフカーブノードには対応しません。各マスターのノード数が一致する保証はないため、可変フォントの互換アウトライン生成は対象外です。

## 開発者向け

幾何処理は `variable_stroke_core.py`、Glyphs との変換は `glyphs_bridge.py` にあります。両プラグイン内の同名ファイルは配布用コピーです。テストは `python3 -m unittest discover -s tests -v` で実行します。

プラグインのバンドル起動バイナリとツールバーアイコンは GlyphsSDK の Python テンプレートから採用しました。ライセンスは `SDK-LICENSE` を参照してください。
