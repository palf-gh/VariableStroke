# Variable Stroke for Glyphs 3

中心線（スケルトン）から、ノードごとに太さの変わるアウトラインを作る Glyphs 3 プラグインです。編集中は中心線だけを扱い、アウトラインは Glyphs のプレビュー・書き出しの段階で生成されます。アウトラインのノード構成は固定なので、マスター間の補間や可変フォントにもそのまま使えます。

*A Glyphs 3 plugin that turns centerlines into variable-width outlines. You edit only the centerline; the outline is generated for preview and export with a fixed node structure, so masters stay interpolation compatible.*

## 動作環境

- Glyphs 3
- Glyphs の Python モジュール（vanilla を含む）

## インストール

1. `VariableStrokeTool.glyphsTool` と `VariableStrokeExport.glyphsFilter` の両方を Glyphs 3 の Dock アイコンへドラッグします。
2. Glyphs の Python モジュールを入れておきます（ウインドウ → プラグインマネージャ → Modules）。
3. Glyphs 3 を再起動します。

## はじめかた

1. 編集画面で、中心線となるパス（開いたパス・閉じたパスのどちらでも可）を描きます。
2. ツールバーの **可変ストローク** ツールを選ぶと、画面下部に専用パネルが表示されます。
3. パネルの **ON** を押すと、そのグリフのパスがストロークになります（初期の太さは40ユニット）。
   - ON / OFF はグリフ単位です。パスの選択は不要で、パスがまだないグリフも ON にできます。
   - 右クリックの「可変ストローク」サブメニュー（編集画面・グリフ一覧）からも、複数グリフをまとめて切り替えられます。
4. 太さ・線端・角丸をパネルやキャンバスのハンドルで調整します。

中心線とそのベジェハンドルは、Glyphs の通常の操作で編集できます。どのツールで動かしても、プレビューはすぐ更新されます。

## パネル

パネルの値は、選択中のパス（未選択時はレイヤーの全ストローク）に対して働きます。ノード単位の値は、選択中のノード（未選択時は対象パスの全ノード）に働きます。

上段はパスの太さで常に表示され、下段は右上のタブで切り替えます。

```
[ON|OFF]  幅[ ]  高さ[ ]  ↺            [ノード|線端|角丸]  ⚙
─────────────────────────────────────────────────────
ノード：幅[ ]%  高[ ]%  位置[ ]%  角度[ ]°
線端：  始点 [線端アイコン][角度]°   終点 [線端アイコン][角度]°
角丸：  [ON|OFF]  外 / 内  半径[ ][ ][🔗]  強さ[ ][ ][🔗]  縦横比[ ][ ][🔗]
```

- 選んだタブは次回も保たれます。キャンバスで角丸のハンドルをつかむと「角丸」、太さ・角度・楕円のハンドルをつかむと「ノード」タブに切り替わります。
- 角丸タブの各組は左が外側、右が内側です。端点だけを選んでいるときは「左 / 右」と表示され、左側・右側になります。

| 項目 | 単位 | 内容 |
|---|---|---|
| 幅 | パス | 縦線の太さ（ユニット）。 |
| 高さ | パス | 横線の太さ（ユニット）。斜めの線は幅と高さの中間の太さになります。 |
| ↺ | パス | 個別に指定した幅・高さを解除し、マスターの既定値に戻します。 |
| ノードの幅％・高さ％ | ノード | 幅と高さを別々に倍率指定します。片方が空欄なら、指定した側の％を両方に使います。両方が空欄なら幅％の既定値100％を使います。既存ファイルのノード％は幅％として読み込み、高さ％は空欄のため従来どおり両方に適用されます。 |
| 位置 | ノード | 中心線が線幅のどこにあるか（％）。0 で中央、100 でパスの進行方向の左側、−100 で右側に寄ります。 |
| 角度 | ノード | 幅と高さの軸をページ上で回転します。0°は幅が水平、90°は幅が垂直です。未指定ならマスターの既定角度に従います。 |
| 始点・終点 | パス | 線端の形。角度欄は角度カット用です。 |
| 角丸 | ノード | 角丸の ON / OFF と、外側・内側の半径・強さ・縦横比。端点では左側・右側になります。 |
| ⚙ | — | 可変ストローク設定（マスターごとの既定値）を開きます。 |

- マスターの既定値に従っている幅・高さ・角度はグレーで表示されます。
- 数値欄はどれも ↑↓ キーで 1 ずつ、Shift+↑↓ で 10 ずつ増減でき、Tab / Shift+Tab で順に移動できます。
- 入力中の値はその場でプレビューされます。Return、Tab、欄から離れたときに、1回分の取り消し操作として確定します。
- 欄にカーソルが入っただけ（Tab で通過した場合も含む）では、何も変わりません。

## キャンバスのハンドル

どのハンドルも、つかんだ時点でそのノードが選択されます（Shift を押しながらなら追加選択）。

| ハンドル | 表示 | 操作 |
|---|---|---|
| 青い丸 | 楕円線端以外の各ノードの両側（実際に輪郭が通る点。角では外側のマイターの角と内側の交点） | ドラッグで、そのノードの太さ（ノード％）が変わります。Option を押しながらだと反対側を固定して片側だけ動き、位置も変わります。Command を押しながらだと楕円の角度を変えられます。 |
| 楕円上の青い四角・緑の菱形 | 楕円線端の選択ノードに表示される楕円の幅軸・高さ軸の先 | それぞれドラッグでそのノードの幅％・高さ％を個別に変えます。 |
| 紫の丸 | 選択ノード（ベジェハンドルを選択した場合はその所属ノード）の幅軸の先 | ドラッグで幅・高さの軸を回転します。楕円線端ではペン先楕円も表示します。 |
| 角丸の丸（外側はオレンジ、内側は緑） | 角丸が ON のノードの角丸の頂点 | 半径 |
| 角丸の菱形 | 選択中のノードの、角丸の両端 | 片側の長さを変えます（縦横比と半径） |
| 角丸の四角 | 選択中のノードの、角丸の弧の中央から一定距離にある対角線上 | ハンドルをドラッグした位置に合わせて角丸の強さを調整します。 |

## 線端

フラット・丸・楕円・四角・水平カット・垂直カット・角度カットから選びます。閉じたパスでは使いません。

- フラットは線に垂直な切り口、丸は半円、四角は直角の角になります。楕円線端はノードの幅・高さ・角度で決まるペン先楕円の外側半周に沿います。
- カットは、線の両側を端点の向きに延長し、端点を通る線で切ります。
  - 垂直カットは、イタリック角度の方向で切ります。
  - 角度カットは、アイコン横の欄の角度（ページ上、0° が水平、90° が垂直）で切ります。角度を入力すると、その線端は角度カットになります。
  - 線の向きがカット方向とほぼ平行な場合（はみ出しが太さの2倍を超える場合）は、フラットになります。

## 角丸

線の太さとは関係なく、指定した半径でアウトラインの角を丸めます。太い線に小さな角丸を付けることもできます。

- **ON / OFF**：ノードごと・マスターごとに設定します（既定は OFF）。OFF にしても値は残ります。値を入力するとその角丸は ON になります。
- **外 / 内**：ノードで曲がる向きに応じた外側・内側の角です。線端ノードではパスの進行方向から見た左側・右側の角になります（丸・楕円の線端を除く）。
- **半径・強さ・縦横比**：それぞれ外側と内側（線端では左側と右側）に別の値を設定できます。既定では連動し、各項目の「連動」ボタンを押すと独立します。もう一度押すと連動に戻ります。旧ファイルの単一値もそのまま連動値として使います。
- **強さ**：100% で円弧です。小さいほど尖り、大きいほど角張った丸みになります（0〜300%）。
- **縦横比**：100% で対称です。大きいほどパスの進行方向の手前側に長く、小さいほど先側に長く丸めます。

## 可変ストローク設定

**ウインドウ → 可変ストローク設定…**、またはパネルの ⚙ で開きます。

- 開いているフォントのマスターごとに、既定の幅と高さを設定できます。高さが空欄なら40ユニットです。
- 個別の幅を指定していないストロークは、そのマスターの既定値に従います。既定値を変えると、それらがまとめて変わります。マスターごとに幅・高さ・ペン先の既定角度を設定できます。
- 幅と高さは独立しています。パスの幅だけを変えても高さは変わりません。
- **選択マスターのパス個別線幅を既定に戻す** で、ON のグリフにある個別の幅・高さをまとめて解除できます（ノードごとの％は残ります）。

## イタリック

イタリック角度があるマスターでは、垂直カットがイタリック角度の方向に傾きます。線の太さは、ページ上で回転した幅・高さの軸とパスの方向から計算されます。角度0°では縦線が幅、横線が高さになります。

## 補間と書き出し

- **アウトラインの構成は固定**です。中心線の各セグメントは片側につき1本（直線は直線、曲線は三次ベジェ1本）、角は1ノード、丸と楕円の線端は曲線2本（それ以外の線端は直線1本）、角丸は1か所につき曲線1本です。水平・垂直・角度カットでは、輪郭のベジェそのものを延長または切り詰めます。値を変えてもノード数は変わらないので、中心線のノード構成と線端の種類が揃っていれば、マスター間で補間できます。
- 輪郭はまず指定した幅・高さから計算したオフセットに沿います。実際のオフセット曲線が交わる角はその交点で切り詰めます。曲線と直線の角で外側だけが長く伸びる場合は、内側の交点を保ったまま張り出しを抑えます。外側の輪郭は、元の曲線の形と見かけの太さに合わせてベジェの曲がりを強めます。曲線の延長が指定のカット線に届かない場合は、ベジェの終端側を調整してカット方向を保ちます。
- **角丸**：どこかのマスターで ON のノードは、他のマスターでも半径0の角丸として同じ構成になります。補間では OFF のマスターを半径0として混ぜるので、尖った角から丸い角へ滑らかに変わります。
- **補間で作られるレイヤー**（プレビュー欄のインスタンスや、他のプラグインによるマスター間の補間表示）では、ON / OFF と線端の設定を引き継ぎます。幅・高さ・ノード％・位置・ペン先角度・角丸・イタリック角度は、マスター間で補間してから展開します。
- **書き出し**：ストロークを使うと、インスタンスに `PreInterpolationFilter` と `Filter` のカスタムパラメータ（`VariableStrokeExport`）が自動で追加されます。補間の前に各マスターをアウトライン化するので、可変フォントでもそのまま書き出せます。`Filter` は補間後の合体と、未変換パスの予備の変換を行います。
- **重なり合体**：Glyphs の OTF 出力画面にある「重なったパスを合体」がオンの場合だけ、出力用の輪郭を Glyphs 本体の合体処理に渡す前に Skia PathOps でも合体します。オフの場合は生成した輪郭の重なりを保持します。単一マスターではアウトライン化直後、複数マスターでは補間後の `Filter` で合体し、補間前のノード構成を保ちます。出力プラグインには macOS 用 Skia PathOps を同梱しています（BSD-3-Clause、ライセンスは `VariableStrokeExport.glyphsFilter/Contents/Resources/vendor/pathops/LICENSE`）。

## アウトライン化

右クリックの「可変ストローク → アウトライン化」、または **フィルタ → 可変ストローク：アウトライン化** で、中心線を実際のアウトラインに置き換え、可変ストロークをオフにします。元の中心線は残らないので、必要なら事前にレイヤーを複製してください。

## 仕組み

- ストロークが ON のとき、Glyphs がプレビュー・他グリフの表示・サイドベアリングの計算のために準備するレイヤーのコピー（`GSPrepareLayerCallback`）の中でだけ、中心線をアウトラインに置き換えます。編集レイヤーには中心線だけが残るので、アウトラインのノードは表示されません。
- 角を動かしても形が急に切り替わらないよう、マイターの長さの制限や、ほぼ一直線の角では滑らかに移行します。
- 計算したアウトラインは入力（ノード位置・太さ・線端・角丸）ごとに保存して使い回します。ノードを動かしている間に計算し直すのは、形が変わったパスだけです。キャンバスの青いハンドルも同じ計算結果から取り出します。
- パネルはツール自身のインスペクタとして表示します。ノードのドラッグ中はパネルを更新しません（マウスを離したときにまとめて更新します）。

## 動作の計測（開発者向け）

動作が重いと感じたときは、マクロパネルで次を実行すると原因を調べられます。

```python
Glyphs.defaults["com.codex.VariableStroke.profile"] = True
```

- 可変ストロークツールでドラッグして離すたびに、処理ごとの所要時間の表がマクロパネルに出ます。
- どのツールでも、マウスを押している間の編集ビューの描画間隔（`Frame timing`）が出ます。標準の選択ツールと比べるのに使えます。
- 止めるときは `False` にします。オフの間はほぼ負荷がかかりません。

パネルが表示されないなど、インスペクタの表示に問題がある場合は、次の設定で以前の表示方式（`GSInspectorViewControllersCallback`）に戻せます（Glyphs の再起動が必要です）。ただし、この方式ではノードのドラッグ中にパネルが作り直され、動作が重くなります。

```python
Glyphs.defaults["com.codex.VariableStroke.inspectorMode"] = "callback"
```

## データの保存先

| データ | 保存先 |
|---|---|
| グリフの ON / OFF | グリフの `userData` |
| 幅・高さ・線端・カット角度 | パスの `attributes` |
| ノードの幅％・高さ％・位置・回転・角丸 | ノードの `userData` |
| マスターの既定の幅・高さ・角度 | マスターの `userData` |

以前の版で保存したノードごとの絶対幅は、ファイルを開いたときに、パス内の最大幅を基準にした％へ換算されます。

## 制限

- 直線と三次ベジェに対応します。二次ベジェや、孤立したオフカーブノードには対応しません。
- 線が曲率半径より太い急カーブでは、内側の輪郭が尖ったり交差したりします（ノード数は変わりません）。
- 線がちょうど真後ろへ折り返す角では、角の形が切り替わります。

## 開発者向け

- 幾何処理は `variable_stroke_core.py`、Glyphs とのやりとりは `glyphs_bridge.py` にあります。両プラグインのバンドル内にある同名ファイルは配布用のコピーです。
- テストは次のコマンドで実行します。

  ```bash
  python3 -m unittest discover -s tests -v
  ```

- プラグインのバンドル起動用バイナリとツールバーアイコンは、GlyphsSDK の Python テンプレートから採用しています。ライセンスは `SDK-LICENSE` を参照してください。
