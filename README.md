# Variable Stroke for Glyphs 3

中心線から可変幅のアウトラインを作る Glyphs 3 プラグインです。

## インストール

`VariableStrokeTool.glyphsTool` と `VariableStrokeExport.glyphsFilter` の両方を Glyphs 3 の Dock アイコンへドラッグし、Glyphs 3 を再起動してください。Glyphs の Python モジュールも必要です（ウインドウ → プラグインマネージャ → Modules）。

## 使い方

1. 編集画面で中心線となる開いたパス、または閉じたパスを描きます。ON/OFF の切り替えにパスの選択は不要です。
2. ツールバーで **可変ストローク** を選ぶと、画面下部のインスペクタに専用の操作パネルが表示されます（`GSInspectorViewControllersCallback` で登録）。**ストローク** の **ON** / **OFF** を選びます。初期幅は40ユニットです。ON/OFF はグリフ単位で保存されます。右クリックの「可変ストローク」からも切り替えられます。
3. パネルの **幅** と **高さ** はパスごとの基準値（ユニット）です。幅は縦線の太さ、高さは横線の太さで、斜めの線はその中間の太さになります。輪郭は常にノードの向きに垂直な位置に置かれるので、フラットは垂直な切り口、丸は半円、四角は直角の角になります。イタリック角度があるマスターでは、高さの軸と垂直カットがイタリック角度の方向に傾き、斜めのステムは水平方向に測った太さが幅になります。個別に指定していないパスはマスターの既定値に従い、グレーで表示されます。↺ ボタンで個別の幅・高さを解除して既定に戻せます。**位置** は選択ノードでの中心線の位置（％）で、0 が中央、100 で線幅がパスの進行方向の左側、−100 で右側に寄ります。**ノード** 欄は選択ノードの太さを線幅に対する％で指定します。数値欄はどれも ↑↓ キーで1ずつ、Shift+↑↓ で10ずつ増減でき、Tab / Shift+Tab で順に移動できます。入力中の値はその場でプレビューされ、Return・Tab・欄から離れたときに1回分の取り消し操作として確定します（ノード未選択時は対象パスの全ノード）。線幅を変えると各ノードの％を保ったまま一括で太さが変わります。青い幅ハンドルは各ノードで実際に輪郭が通る点（角のノードでは外側のマイターの角と内側の交点）にあり、ドラッグするとそのノードの％が変わります。Option を押しながらドラッグすると反対側を固定したまま片側だけ動き、位置も変わります。中心線とベジェハンドルは Glyphs の通常の操作で編集できます。
4. **始点** と **終点** のアイコンで線端を選びます（フラット・丸・四角・水平カット・垂直カット・角度カット）。カットは、線の両側を端点の向きに延長し、端点を通る線で切ります。垂直カットはイタリック角度の方向、角度カットはアイコン横の欄で指定した角度（ページ上、0° が水平、90° が垂直）です。角度を入力するとその線端は角度カットになります。閉じたパスでは線端設定は使いません。
5. 右クリックの「可変ストローク → アウトライン化」、または **フィルタ → 可変ストローク：アウトライン化** で手動変換できます。元の編集データを残すには、変換前にレイヤーを複製してください。

ONにすると、Glyphs の `GSPrepareLayerCallback` で、Glyphs がプレビュー用に準備するレイヤーのコピーの中だけ中心線をアウトラインに置き換えます。編集レイヤーには中心線だけが残り、アウトラインのノードは表示されません。プレビュー（スペースキー、プレビュー欄）、テキスト中の他グリフ、サイドベアリングは Glyphs 標準の仕組みで更新されるので、どのツールで中心線を動かしてもすぐ反映されます。アウトラインのノード構成は固定です。中心線の各セグメントは片側につき1本（直線は直線、曲線は三次ベジェ1本）になり、角は1ノード（外側はマイター点、内側は交点。ノードを動かしても角の形が急に切り替わらないよう、マイター制限や一直線に近い角では滑らかに移行します）、線端は丸以外すべて直線1本、丸は円弧2本です。形が変わってもノード数は変わらないため、各マスターのキャップ設定と中心線のノード構成が揃っていれば補間互換になります。書き出しでは `PreInterpolationFilter` が補間前に各マスターをアウトライン化し（可変フォントを含む）、`Filter` は予備として同じ変換を行います。どちらもインスタンスへ自動追加されます。アプリ内のインスタンスのプレビューでは、線幅もマスター間で補間されます。

右クリックの「可変ストローク」サブメニューは編集画面とグリフ一覧で利用でき、グリフごとに ON / OFF とアウトライン化を選べます。ON で対象グリフの各レイヤーのパスを中心線として扱います。パスがまだないグリフも ON にできます。

### 可変ストローク設定

**ウインドウ → 可変ストローク設定…**、またはパネルの ⚙ ボタンで開きます。現在のフォントのマスターごとに既定の幅と高さを設定できます（高さが空欄なら幅と同じ）。値を変えると、そのマスターで個別の線幅を持たないストロークがすべて追従します。**選択マスターのパス個別線幅を既定に戻す** で、ON のグリフにある個別の線幅をまとめて解除できます（ノードごとの％は残ります）。既定線幅はマスターの `userData` に保存されます。

## データと制限

- パスの設定と基準の線幅は `attributes`、ノードごとの％は `userData` に保存されます。幅は中心線から両側へ対称です。以前の版で保存したノードごとの絶対幅は、ファイルを開いたときに最大幅を基準の線幅とした％へ換算されます。
- 水平・垂直カットは端点を通り、ページ座標に固定されます。パスの進行方向がカット線とほぼ平行な場合、端部に鋭い折り返しが生じることがあります。
- 直線と三次ベジェに対応します。二次ベジェ、孤立したオフカーブノードには対応しません。
- 線幅が曲率半径より大きい急カーブでは、内側の輪郭が尖ったり交差したりします（ノード数は変わりません）。
- 水平/垂直カットは、線の向きがカット方向とほぼ平行（はみ出しが線幅の2倍を超える）な場合はフラットになります。

## 開発者向け

幾何処理は `variable_stroke_core.py`、Glyphs との変換は `glyphs_bridge.py` にあります。両プラグイン内の同名ファイルは配布用コピーです。テストは `python3 -m unittest discover -s tests -v` で実行します。

プラグインのバンドル起動バイナリとツールバーアイコンは GlyphsSDK の Python テンプレートから採用しました。ライセンスは `SDK-LICENSE` を参照してください。
